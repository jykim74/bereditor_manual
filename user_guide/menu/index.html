BerEditor Menu Description

File

New

Open BerEditor in a new window

Open

Open BER, DER, or PEM files

Open Certificate

Displays the certificate file in detail.

Open CRL

Displays the CRL file in detail.

Open CSR

Displays the CSR file in detail.

Open PrivateKey

Displays the private key file in detail.

Open PublicKey

Displays the public key file in detail.

Open CMS

Displays the CMS file in detail.

Save

Saves the current BER value.

Save As

Save the current BER value under a different name.

Recent Files

Print

Print the BER data.

Print Preview

Preview BER data

Edit

Copy Information

Copy current node information to the clipboard

Copy As Hex

Copy the current node hex value to the clipboard.

Copy As Base64

Copy the current node base64 value to the clipboard.

Expand All

Expand all tree nodes

Expand Node

Expand current tree nodes

Collapse All

Collapse all tree nodes

Collapse Node

collapse current tree nodes

Previous Node

Moving from the current node to the previous node

Next Node

Moving from the current node to the next node

Find

Finding nodes within BER data

View

Tool

Decode BER

Decoding the input BER data

Data Convertor

Tool for changing character data encoding formats

Num Convertor

Tool for converting numbers between binary, decimal, and hexadecimal formats.

OID Information

Information on various representations of OID values

Make BER

Tool for generating BER data

Check BER

Function to check the type of BER data

Get BER from URI

Retrieving BER data using HTTP or LDAP

BER Compare

Compare two BER data sets to indicate the presence of identical data and differences.

Binary View

View BER data in binary format.

Text View

View BER data in tet format.

Cryptography

Key Manage

Generating key derivation and wrapping values, such as KeyDerive, KeyWrap, and KEM.

Hash

Calculating various digest values, such as SHA

Message Authentication Code

Generating message authentication code values ​​such as HMAC and CMAC

Encrypt/Decrypt

Encrypting or decrypting input values ​​or files using a symmetric key

Sign/Verify

Generate a signature value for an input or file using an asymmetric key, or verify a generated signature value.

PubKey Encrypt/Decrypt

Performing asymmetric key operations: public key encryption and private key decryption.

Key Agreement

Obtaining a key agreement value using DH or ECDH

PKCS7

Creating signed and encrypted data in PKCS#7 format

Shamir Secret Sharing

Splitting and merging the key using the Shamir Secret Sharing algorithm

Certificate Path Validation

Perform path validation for the certificate.

OTP Generator

Generating a numeric One-Time Password value

VID

Generating and Verifying Virtual ID Values Used in Joint Certificates

BN Calculator

Calculator for large numbers

Make PrivateKey

Generating asymmetric key algorithm public or private key values in BER format.

Service

KeyPair Manage

Providing functions for the use, management, and selection of various asymmetric key pairs.

Certificate Manage

Provide functions for the use, management, and selection of various certificates and private keys.

Key List

Provide functions for the use, management, and selection of various symmetric keys.

SSL Check

Retrieving certificate information used for the SSL/TLS handshake with an HTTPS server.

X509 Compare

Comparing Certificates, CRLs, and CSR Files for Identity and Differences

Document Signer

Signing and Verification of CMS, JWS, and XML Documents

PDF Signer

Signing and Verifying PDF Documents

CAVP

Generating Results for CAVP Requests

Protocol

OCSP Client

OCSP Client Functionality and Analysis of Request and Response Messages

TSP Client

TSP Client Functionality and Analysis of Request and Response Messages

CMP Client

CMP Client Functionality and Analysis of Request and Response Messages

SCEP Client

SCEP Client Functionality and Analysis of Request and Response Messages

ACME Client

ACME Client Functionality and Analysis of Request and Response Messages

EST Client

EST Client Functionality and Analysis of Request and Response Messages

KMIP

Decode TTLV

Decoding the entered KMIP message

Make TTLV

Generating KMIP messages

TTLV Encoder

Generating various request commands used in KMIP

TTLV Client

Sending request messages and receiving response messages as a KMIP client
